# Enterprise discovery guide

**Status:** reusable interview guide, informed by the author's GrapeRoot responsibilities. It is not a transcript of historical interviews.

## Learning goals

1. Understand the workflow around AI-assisted coding and codebase context.
2. Identify the cost of the current problem in time, tokens, quality, and trust.
3. Learn who experiences the problem, who evaluates it, and who pays.
4. Separate a feature request from a buying requirement.
5. Define the smallest pilot that can produce evidence.

## Questions

- Tell me about the last time an AI coding tool struggled with an unfamiliar repository.
- What did the developer do next? How much time or AI usage did that consume?
- Which repositories, agents, editors, and deployment environments matter?
- What would make you trust a context tool with source code?
- What would block team-wide rollout?
- Who needs to approve access, security, procurement, and spend?
- What evidence would justify paying for this workflow?

Avoid leading with the product solution. Ask for a recent episode before asking whether a proposed feature sounds useful.

## Synthesis template

For each conversation, record the date, participant type, observed workflow, problem evidence, current workaround, urgency, buying role, exact request, confidence, and follow-up. Do not publish names or quotes without consent.
